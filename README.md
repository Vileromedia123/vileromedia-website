# VileroMedia website

One-page site for VileroMedia — Google Ads & LSA for US residential roofers.
Next.js + Tailwind, deployed on Vercel, contact form saved in Supabase (`leads` table).

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # must pass before any pull request
```

Brand and content rules: see `AGENTS.md`. Database setup: `supabase/leads.sql`.
